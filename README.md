# 青风 Agent

青风的独立浏览器前端，发布到 GitHub Pages。仓库只包含 HTML、CSS、JavaScript、浏览器排版资源和 Pages 发布配置。

后端程序、模型配置、密钥、用户文件和对话历史不在此仓库内。

## 使用

打开页面，点击“连接青风”，填写私有访问码。当前测试地址为 **https://111.115.201.25:18443**，直接连接 HPC，不经过云服务器中转。访问码只保存在当前标签页内存中，以 Web Crypto 生成一次性请求证明，不写入浏览器存储或仓库。刷新页面后需要重新输入。

当前按所有者要求使用 IP 自签名测试证书，有效期至 2026-11-27。每台电脑首次使用前，需所有者本人先打开上述 HTTPS 地址并完成浏览器的证书确认，再回到网页连接。前端无法替浏览器接受证书；没有完成这一步时，提问和文件请求会被浏览器阻止。证书私钥始终留在 HPC，未包含在本仓库中。

服务地址可以在 `site-config.json` 的 `apiBase` 中设置为公开 HTTPS API 域名；也可以保持空值，由用户在连接面板输入。不要在配置文件中放置访问码或供应商密钥。

GitHub Pages 只托管前端，模型运行、文件读取和历史保存仍由原 Agent 后端负责。HTTPS 页面不能直接连接普通 HTTP API。API 网关必须支持前端来源的 CORS、OPTIONS 预检，并转发签名请求，不能把浏览器请求自动转换为无认证的单用户请求。

## 展示与交互

- 正文逐步到达并渐进显示；完整代码块、公式、表格和图示独立排版。
- 支持 Markdown、KaTeX 公式、结构化答案、折线/柱形/散点图和 Mermaid 图。
- 坏图保留原始代码和错误提示，不影响相邻内容；可本地重新排版。
- 上传显示进度，中断后重新选择同一文件续传；不会自动重发聊天生成。
- 原会话、来源、文件统计与图表、Word/Excel 导出按后端实际能力显示。
- 断线后继续读取已知任务；未确认的提交保留输入，明确说明没有自动重发。
- 支持窄屏、键盘操作、中文输入法、减少动画偏好和用户自主滚动。

所有资源使用相对路径，兼容 `https://用户名.github.io/仓库名/` 子目录。浏览器依赖保存在 `assets/vendor`，版本和校验值见其中的清单；保留相应上游许可证。

## 发布

在仓库 Settings → Pages 选择 GitHub Actions，启用本仓库的 Pages 工作流。公开站点是否能从私有仓库发布取决于 GitHub 套餐；不支持时，需要将仅含前端的仓库设为公开，或使用支持私有仓库 Pages 的套餐。

发布内容仅为前端静态文件。GitHub Actions 中不需要 Agent 密钥，也不执行后端安装、模型调用或服务器部署。
